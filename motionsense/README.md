# Oslo production SystemUI plugins

Pixel 4 XL logs from 13 October 2026 show both Oslo plugins rejected with
`Plugin cannot be loaded in production`, while Motion Sense and glow are
enabled and the plugin permission is granted. SystemUI also logs `No such file
or directory` when opening the autogenerated product and vendor SystemUI
overlay APK paths. Those overlays contain the device's production allowlist.
An OverlayManager lookup showing that array does not prove SystemUI can open
the corresponding APK in its process.

`GoogleOsloSystemUIOverlay` provides the production allowlist through a separate
static, platform-signed overlay in `system_ext`. Its path is independent of the
autogenerated product/vendor APK names. It preserves the existing Infinity
plugin entries and includes both explicit Oslo components:

- `com.google.oslo/com.google.oslo.OsloOverlay`
- `com.google.oslo/com.google.oslo.OsloSensorManager`

The Android 17 `PackageConfig` accepts these components and also derives their
package privilege for the plugin class-loader gate. Plugin permission and
interface-version checks continue through SystemUI's normal loader.

Source checked: ProjectInfinity-X `frameworks_base` branch `17`, commit
`793c6f6e70f79c449abf91aee87d2071be619f35`, especially `PackageConfig.kt`,
`PluginActionManager.kt`, `PluginInstance.kt`, and `PluginsModule.kt` under
`packages/SystemUI`. Both package and component entries are supported: changing
the spelling of the old package entry alone would not address the missing APKs.

This targets the confirmed production plugin rejection without a framework
patch. The reason the generated overlay paths are inaccessible remains an
on-device investigation; it may also affect other overlaid SystemUI settings.
Final Oslo loading, glow and radar behavior still require phone verification.

After syncing and rebuilding, confirm this file is in the ROM output:

```bash
ls -l out/target/product/coral/system_ext/overlay/GoogleOsloSystemUIOverlay.apk
```

After flashing, check that the overlay is installed and active:

```bat
adb shell cmd overlay list --user 0 com.android.systemui
adb shell ls -l /system_ext/overlay/GoogleOsloSystemUIOverlay.apk
```

Test music gestures, the Motion Sense training room, glow preview, and music
glow. Capture SystemUI startup if either plugin is still rejected. The custom
Sidekick wallpapers remain removed from this branch.
